# Taskbar Lyrics

网易云音乐任务栏歌词插件，支持多种歌词格式与显示效果。

> AI更新自 https://github.com/mo-jinran/Taskbar-Lyrics

## ✨ 新增功能 (v1.x.x)

### 🎵 歌词支持升级
- **YRC 动态歌词**：全面支持 YRC 格式，带来更精准的逐字歌词显示体验。
- **逐字歌词 (Karaoke)**：新增卡拉 OK 模式，歌词随进度逐字高亮。
- **多语言支持**：完美支持翻译歌词与罗马音显示，满足不同语言歌曲需求。

### 🚀 性能与稳定性
- **WebSocket 通信**：底层通信重构为 WebSocket 协议，数据传输更即时、更稳定。
- **心跳检测**：内置心跳机制，自动维持连接活跃，断线自动重连。
- **自动重启**：插件进程异常退出时支持自动重启，确保歌词显示不中断。

### ⚙️ 个性化配置
- **字体大小调节**：支持独立设置主歌词与副歌词的字体大小。
- **资源优化**：优化了歌词渲染的资源管理，降低系统占用。

## 🛠️ 技术重构
- 代码结构全面重构，模块化更清晰。
- 为所有核心模块添加了详细的 JSDoc 注释，便于维护。
